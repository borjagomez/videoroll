Approve a time off request

Managers review their team's time off requests from the Time off section. Approving a request updates the employee's balance and notifies them by email.

Before you start. You need the Manager role, and the request must still be in Pending status.

Steps

  1. In the left sidebar, click Time off.
  2. Find the request you want to decide on in the list of pending requests.
  3. Click Approve on that row.
  4. Optionally write a note for the employee in the dialog that opens.
  5. Click Confirm approval.

What happens next

The row's status changes to Approved and a confirmation appears at the bottom of the screen.
