Reject a time off request

If a request cannot be accommodated, reject it from the same list. The employee is notified and their balance is left untouched.

Before you start. You need the Manager role.

Steps

  1. In the left sidebar, click Time off.
  2. Locate the pending request.
  3. Click Reject on that row.

What happens next

The status changes to Rejected immediately - rejection is not confirmed in a dialog.
